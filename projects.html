13-Week Curriculum Timeline

Course Outlines & Lecture Roadmap

Weekly progression of internet programming methodologies, protocols, client/server technologies, and database integration based on the official syllabus:

Timeline Curriculum Topics & Core Concepts Practical Lab / Project Focus Tech Stack
Week 1 Internet Foundations & Protocols: Fundamental internet programming concepts, TCP/IP, HTTP protocol structure, browser caching, cookies, and HTML foundations. HTML5 semantic document skeleton, structuring web hierarchy. HTML5, HTTP/1.1
Weeks 2–3 CSS Styling & JavaScript Essentials: Inline, document, and external CSS. JavaScript variables, control flow, functions, strings, arrays, and classes. Assignment 01: Multi-page personal profile, responsive styling, and class schedule table. CSS3, Flexbox, Grid, ES6 Basics
Weeks 4–5 Dynamic Client-Side Programming: Client-side scripting with form elements, event listeners, dynamic DOM manipulation, and event-driven architecture. Assignment 02: Dynamic interactive web application with event callbacks and form checkers. Vanilla JS, DOM API, Event Loop
Weeks 6–7 Server-Side PHP Foundations: Event calls from JS to PHP, PHP forms processing, file I/O, cookies, date/time functions, and form data verification. Assignment 03: Server-side form checker, file operations, and cookie-based preferences. PHP 8+, HTTP POST/GET, Cookies
Week 8 Advanced PHP & Sessions: Object-Oriented PHP (classes, encapsulation), session state management, and Midterm Examination review. Stateful authentication sessions, login/logout access control guards. OOP PHP, Sessions, Auth
Weeks 9–11 MySQL Database Integration: Relational schema design, tables, data types, primary/foreign keys, and full CRUD PHP/MySQL application development. Assignment 04: Database-backed web portal, data persistence, and prepared statements. MySQL, PHP PDO, CRUD
Week 12 Advanced SQL & PHP Security: Relational joins, SQL aggregations, indexing, and prevention of SQL Injection and Cross-Site Scripting (XSS). Database normalization, query optimization, input sanitization defense. Advanced SQL, Web Security
Week 13 Emerging Technologies & AJAX: Asynchronous JavaScript & XML (AJAX), JSON exchange, introductory XML, web frameworks, and final capstone project. Final Project: Full-scale commercial website clone implementation and IEEE-style Term Paper. AJAX, JSON, Full-Stack PHP/MySQL
